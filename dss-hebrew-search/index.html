      How to read the results
      • The highlighted word is the hit; the words around it come from the same scroll fragment. A / marks the end of a line.
      • Faded in brackets: reconstructed by an editor. Dotted underline: partly reconstructed. Wavy underline: uncertain letters. Struck through: removed by an editor. Solid underline: corrected.
      • “Reconstructed text” in the search form leaves out hits that rest on editors’ reconstruction: a fully reconstructed word is one where every letter was supplied by an editor; the stricter option also drops words where only some letters were.
      • The dataset writes prefixes (ו ה ב כ ל מ ש) as separate units; this page joins them to the word they belong to. A lexeme search uses the dataset’s own lexeme for each word, so it finds every inflected form.
      • The Biblical parallels tab lines manuscripts up verse by verse using the dataset’s own book, chapter and verse labels. Manuscripts the dataset could not place in a book are not included. Each cell links to that line in the Read tab.
      • References are scroll, fragment or column, and line, as numbered in the dataset. They can differ by a line from printed editions, so check before you cite.
      • Regular expressions run on the consonants only, with final letters changed to ordinary ones (ן → נ). Final letters in your pattern are changed the same way. For example, ^[והבלמ]?עינ finds words that begin with an optional prefix and then עין.
